# The Scroll

**Paper scroll studio** — an offline web app for clumsy words, poems, and free writing on textured paper that unrolls like a scroll.

- Local poem generation (sonnet, haiku, couplets, limerick, free verse, note) or **Blank** canvas
- Handwriting fonts, papers, inks, stickers, pen strokes
- Library drawer, print / PDF export of the sheet as you see it
- Everything stays in your browser (`localStorage`); no account or API

**Developer:** Akhansha Sen

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Live site

After GitHub Actions runs on `main`, the app is published to GitHub Pages:

https://akhanshasen.github.io/The-Scroll/

In the repo **Settings → Pages**, set **Source** to **GitHub Actions** if it is not already.
